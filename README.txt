Новогодний первый экран «Снежные шары» — готовая сборка

Это статический сайт, серверная часть не нужна. Достаточно загрузить
содержимое этой папки на любой веб-хостинг (nginx, Apache, S3, Netlify,
Vercel, GitHub Pages и т. п.). Сайт работает и из корня домена, и из подпапки.

Важно: двойной клик по index.html (открытие через file://) работать не будет,
браузеры блокируют загрузку модулей и данных с диска. Страницу нужно открывать
через веб-сервер. Для локального просмотра подойдёт, например:

    npx serve .
  или
    python3 -m http.server 8080

Требования к браузеру: актуальные Chrome, Edge, Firefox или Safari с WebGL 2.
Без WebGL показывается статичная версия, совпадающая с макетом.

Исходный код и инструкция по сборке — в архиве ng2027-snowglobes.zip.
